# Manager User Guide

## 1. Role Purpose

The Manager role is used for approval and team oversight.

Managers are expected to:

- submit their own booking requests when needed
- review staff requests assigned to them
- approve or reject those requests before they move to admin

## 2. What Manager Can Access

### Main pages

- `/dashboard`
- `/planner`
- `/approvals`
- `/bookings/new`
- `/bookings/[id]`
- `/my-bookings`
- `/profile`

### Main permissions

- create booking requests
- view planner
- view own booking history
- review assigned staff requests

## 3. What Manager Cannot Do

- cannot manage rooms
- cannot manage users
- cannot access system settings
- cannot access full reports
- cannot directly control admin-only booking settings

## 4. Daily Manager Workflow

### As a requester

1. Open `Request booking`
2. Submit the needed reservation request
3. Monitor request status from personal pages

### As an approver

1. Open `/approvals`
2. Review staff requests assigned to you
3. Open booking details if needed
4. Approve or reject

### Planner use

- Managers can use the planner to check room occupancy before making requests
- Private details of other users’ bookings are restricted

## 5. Approving Staff Requests

### What to review

- room and date
- time
- meeting title
- attendee count
- food service need
- charged company and department

### Manager decisions

- approve: request moves to admin
- reject: request stops and is recorded in audit trail

## 6. Booking Requests

Managers can create their own requests just like staff users.

### What happens after submission

- manager-created requests move directly to admin review
- final confirmation still depends on admin

## 7. Personal Visibility

Managers can see:

- their own bookings
- their own request statuses
- staff requests specifically assigned to them for approval

Managers should not expect to see the private details of unrelated users’ reservations.

## 8. What Manager Should Expect

- A controlled approval role, not a configuration role
- Visibility into team approval tasks
- Planner access for schedule awareness

## 9. Best Practice For Managers

- Review requests quickly to avoid operational delay
- Reject clearly when the request should not proceed
- Use booking details before deciding if the request has special requirements
- Coordinate with admin if room change or escalation is needed
