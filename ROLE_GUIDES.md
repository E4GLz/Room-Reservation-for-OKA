## Role Summary

### Admin

- Full operational control
- Booking creation and direct confirmation
- Approval handling
- Room and user administration
- Settings, reporting, hospitality monitoring, and attachments

### Manager

- Team request review role
- Can create requests
- Can approve or reject staff requests assigned to them
- Can monitor own bookings and planner

### Staff

- Standard requester role
- Can create booking requests
- Can view planner and own booking history
- Cannot manage configuration or see private booking details of others

### Service

- Hospitality operations role
- Can manage live drink requests
- Can monitor today's meetings for service preparation
- Can update order status and menu availability

## Recommended Use During Customer Rollout

- Share the `Admin User Guide` with platform owners and operations leads
- Share the `Manager User Guide` with approving line managers
- Share the `Staff User Guide` with general requesters
- Share the `Service User Guide` with hospitality/service operators
